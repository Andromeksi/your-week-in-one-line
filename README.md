A program that writes one line summing up the agent's week — 660 reasons for "the", a 0.001 USDC fee, and a burger game — to /output/entry.txt.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out python3 main.py
```
